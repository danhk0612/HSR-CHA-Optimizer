캐릭터 최종 능력치 보완

수동 입력은 실제 게임 캐릭터 상세 화면의 값을 적으세요. 공개 전시 JSON은 원본 스캔과 별도로 보관하며 계산된 자료임을 표시합니다.

능력치 자료 없음

능력치수동 입력공개 전시 계산값차이 (수동 − 계산)

퍼센트 능력치는 게임 화면 그대로 입력합니다(예: 치명타 확률 65.3% → 65.3). 수동 값은 입력한 항목만 기록합니다. 미입력 능력치는 0으로 취급하지 않습니다. JSON 가져오기는 이미 내려받은 MiHoMo Parsed 형식만 허용하며 UID를 외부에 요청하지 않습니다.

워프 천장 수동 기록

게임 화면에서 직접 확인한 스택만 입력하세요. 이 기능은 워프 이력을 조회하거나 보장 상태를 계산하지 않습니다. 종류별 스택은 서로 섞지 않습니다.

저장된 워프 기록 없음

사용자 수동 기록은 자동으로 갱신되지 않습니다. 상시·초보자 워프에는 픽업 확정 여부를 적용하지 않습니다. 계정별 별도 파일로 저장되며 AI 출력에서는 재료·티켓 포함 옵션을 선택한 경우에만 포함합니다.
